# 🔦 Project Heist (가제: Perfect Crime)
> [cite_start]**"우당탕탕! 1명의 경찰과 4명의 도둑이 벌이는 대환장 대탈출!"** [cite: 1, 2]

## 📖 게임 소개
[cite_start]**Project Heist**는 1명의 경찰과 4명의 도둑이 맞붙는 **비대칭 협동 PVP 파티 게임**입니다[cite: 1, 2]. 
[cite_start]도둑들은 건물 내부로 잠입해 협동하여 물건을 훔치고 트럭으로 탈출해야 하며, 경찰은 소리와 불빛을 단서로 이들을 추적하고 체포해야 합니다[cite: 1]. 

[cite_start]어두운 건물 속 스릴 넘치는 스텔스는 물론, 무거운 물건을 함께 나르다 동선이 꼬이고 경찰에게 쫓기며 물건을 다 쏟아버리는 코믹한 상황이 끊임없이 펼쳐집니다[cite: 1].

## 🎮 게임 규칙
### 🏆 승패 조건
* [cite_start]**도둑팀 승리**: 할당량 이상의 물건을 도주 트럭에 싣고 무사히 출발시키면 승리! [cite: 1]
* [cite_start]**경찰 승리**: 트럭이 출발하기 전에 도둑 4명을 전원 체포하거나, 트럭이 출발하더라도 사보타지를 통해 물건을 떨어뜨리게 만들어 목표 금액 달성을 막으면 승리! [cite: 1]

### 🐾 역할 소개
**🥷 도둑 (4인)**
* [cite_start]**목표:** 맵 곳곳에 배치된 물건을 훔쳐 트럭으로 옮기기[cite: 1].
* [cite_start]**특징:** 어둠 속에서도 시야 제한 없이 모든 것을 볼 수 있습니다[cite: 1]. 
* [cite_start]**협동:** 무겁고 비싼 물건일수록 여러 명이 함께 들어야 빠르게 이동할 수 있습니다[cite: 1]. [cite_start]잡힌 동료의 뒤통수를 쳐서 구출할 수도 있습니다[cite: 1].

**👮 경찰 (1인)**
* [cite_start]**목표:** 손전등과 소리를 단서로 도둑들을 찾아내어 영구 탈락(경찰차 이송) 시키기[cite: 1].
* [cite_start]**특징:** 시야는 손전등이 비추는 곳으로 제한되지만, 도둑의 발소리나 물건 떨어지는 소리를 듣고 위치를 추적할 수 있습니다[cite: 1].

## ✨ 핵심 시스템
* [cite_start]**비대칭 시야 시스템**: 경찰은 오직 손전등 빛으로만 도둑을 찾을 수 있고, 도둑은 경찰의 빛을 피해 숨어 다녀야 하는 긴장감 넘치는 스텔스 환경[cite: 1].
* [cite_start]**데이터 드리븐 사운드 탐지**: 발소리, 물건 떨어지는 소리, 심지어 보이스 채팅 소리까지 물리적으로 계산되어 경찰의 레이더에 잡히게 됩니다[cite: 1].
* **물리 기반 협동 운반**: 무거운 물건을 혼자 끌면 소음이 커지고 느려집니다. [cite_start]두 명이서 타이밍을 맞춰 옮겨야 살 수 있습니다[cite: 1].
* **최종 탈출 격전**: 트럭 시동을 거는 순간 위치가 발각됩니다. [cite_start]도둑은 문을 닫으려 하고, 경찰은 문을 열어젖히려는 마지막 사보타지 전투가 벌어집니다[cite: 1].
