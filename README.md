## 📖 게임 소개
**Project Heist**는 1명의 경찰과 4명의 도둑이 맞붙는 비대칭 협동 PvP 파티 게임입니다.
도둑들은 건물 내부로 잠입해 협력하여 물건을 훔쳐 트럭으로 탈출해야 하며, 경찰은 소리와 불빛을 단서로 이들을 추적하고 체포해야 합니다.

어두운 건물 속 스텔스의 긴장감은 물론, 무거운 물건을 함께 나르다 동선이 꼬이거나 경찰에게 쫓겨 우당탕탕 짐을 쏟아버리는 코믹한 상황이 끊임없이 펼쳐집니다.

## 🎮 게임 규칙
### 🏆 승패 조건
* **도둑팀 승리**: 할당량 이상의 물건을 도주 트럭에 싣고 무사히 출발시키면 승리!
* **경찰 승리**: 트럭 출발 전 도둑 4명을 전원 체포하거나, 트럭이 출발하더라도 사보타지를 통해 물건을 떨어뜨려 목표 금액 달성을 막으면 승리!

### 🐾 역할 소개
**🥷 도둑 (4인)**
* **목표:** 건물 내 물건을 훔쳐 트럭으로 탈출.
* **특징:** 어둠 속에서도 시야 제한이 없어 경찰의 위치를 쉽게 파악할 수 있습니다.
* **협동:** 무겁고 비싼 물건은 여러 명이 들어야 하며, 경찰에게 잡힌 동료의 뒤통수를 쳐서 구출할 수 있습니다.

**👮 경찰 (1인)**
* **목표:** 도둑들을 체포하여 경찰차로 이송(영구 아웃)시키기.
* **특징:** 시야는 손전등이 비추는 좁은 곳으로 제한되지만, 도둑의 발소리나 운반 소음을 듣고 방향을 추적할 수 있습니다.



## 🕹️ 조작 방법
이동 방향과 캐릭터가 바라보는 방향(마우스)이 완벽하게 분리되어 있어, 뒷걸음질 치며 도망가거나 주변을 경계하며 이동할 수 있습니다.

| 키 | 동작 | 설명 |
| :--- | :--- | :--- |
| **W, A, S, D** | 캐릭터 이동 | 월드 기준 상하좌우로 이동 |
| **마우스 이동** | 시야 회전 | 캐릭터 및 손전등이 바라보는 방향 조절 |
| **LMB (좌클릭)** | 상호작용 | 물건 집기/내려놓기, 수갑 장착/해체, 회복, 도둑 이송, 트럭 문 열고 닫기 등 상황에 맞게 작동 |
| **F** | 공격 | 도둑은 발차기, 경찰은 제압봉 공격 |
| **Shift** | 살금살금 걷기 | 이동 속도가 느려지지만 소음이 없음 |



## ✨ 핵심 시스템 (Key Features)
* **비대칭 시야 및 스텔스 (Advanced Vision)**: 경찰은 손전등 빛(Cone)으로만 도둑을 찾을 수 있고, 도둑은 빛을 피해야 합니다. [cite_start]실내/외 구역에 따라 가시성이 동적으로 변합니다.
* **데이터 드리븐 사운드 탐지 (Audio Detection)**: 발소리, 물건 떨어지는 소리가 물리적으로 계산됩니다. 부상(x1.8)이나 물건 운반(x1.5) 상태일 때 소음이 커집니다. 클라이언트 핵 방지를 위해 탐지 연산은 100% 서버에서 처리됩니다.
* **물리 기반 협동 운반 (Dynamic Carry)**: 권장 인원보다 적은 인원이 무거운 물건을 끌면 이동 속도가 대폭 감소하고 소음이 커지는 페널티가 발생합니다.
* **최종 탈출 격전 (Last-Write-Wins)**: 트럭 시동 시 위치가 전역에 노출됩니다. 도둑은 문을 닫으려 하고, 경찰은 문을 열어 사보타지하는 최종 눈치싸움이 벌어집니다.

## 💻 개발 환경 및 기술 스택 (Tech Stack)
* **Engine**: Unreal Engine 5
* **Language**: C++, Blueprints
* **Framework**: GAS (Gameplay Ability System) 전면 도입
* **Network**: Listen Server (Steam OSS) 기반 멀티플레이
* **Architecture**: Thin Class 원칙 및 MVC 패턴 UI 디커플링 적용
